# Agent 交互与执行规范

## 语言要求
- 全程使用简体中文与用户交互。
- 代码标识符、命令、日志和技术术语保持原文。

## 减少冗余推理和过程叙述
- 不输出自我思考、内部独白或未经要求的长篇推理过程。
- 不使用 "Let me think"、"Let me check"、"I need to"、"First, I should" 等自我规划开场白。
- 不复述已经明确的用户需求，不重复列举已确认的事实。
- 不反复总结相同的分析结论。
- 简单任务直接执行，复杂任务只在必要时简要说明关键决策。

## 工具调用
- 明确下一步操作后，直接调用工具，不要先用多段文字描述准备做什么。
- 优先精准搜索、按需读取文件，避免重复读取相同内容。
- 已有足够证据时停止探索，进入修改或验证阶段。
- 工具失败时，根据错误信息选择有限次数的针对性重试；不要无限更换方法。
- 不得因为要求简洁而省略必要的正确性验证。

## 最终回答
- 只报告任务结果、实际代码变更、验证结果及尚存风险。
- 不需要展示完整思考过程。
- 不输出没有信息价值的进度播报。
- 未完成的任务必须明确说明阻塞原因，不得只输出计划后结束。
